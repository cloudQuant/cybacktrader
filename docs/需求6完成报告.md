### 阶段1：position.pyx示例实施（已完成）

#### 实施内容
创建了`_calc_position_delta()`内部cdef函数，用于优化Position类的核心计算逻辑：

**函数签名：**
```cython
cdef inline void _calc_position_delta(
    long oldsize,
    long delta, 
    double old_price,
    double new_price,
    long* out_newsize,
    long* out_opened,
    long* out_closed,
    double* out_price
) noexcept nogil
```

**优化特性：**
1. **C级性能**：完全在C层面执行，无Python调用开销
2. **内联优化**：使用`inline`关键字减少函数调用开销
3. **GIL释放**：使用`nogil`允许并行执行
4. **零拷贝**：通过指针直接返回多个值
5. **类型安全**：编译时类型检查

**修改的方法：**
- `Position.update()` - 现在内部调用`_calc_position_delta()`

#### 优化后代码（C级实现）
```python
def update(self, size, price, dt=None):
    self.price_orig = self.price
    
    # 调用C级辅助函数
    cdef long oldsize = self.size
    cdef long delta = size
    cdef long newsize, opened, closed
    cdef double new_price_result
    
    _calc_position_delta(
        oldsize, delta, self.price, price,
        &newsize, &opened, &closed, &new_price_result
    )
    
    # 更新状态
    self.size = newsize
    self.price = new_price_result
    self.upopened = opened
    self.upclosed = closed
    
    return self.size, self.price, opened, closed
```
