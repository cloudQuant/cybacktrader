###  核心目标 

把一些类重构成cython的类

###  任务拆解

1. 阅读cython教程，了解如何把python类用cython进行重构：docs/cython_docs/en/stable
2. 阅读整个项目的160多个pyx等cython代码，分析哪些文件中的类可以用cython重构成cython的类
3. 罗列出来这些文件和类，然后做成一个todo清单
4. 一个类一个类进行重构，重构完成一个类就进行验证
5. 使用pip install -U .  进行编译安装，使用pytest tests -n 8 进行测试，看是否所有测试都通过
6. 如果所有测试都通过，那么就提交代码
7. 如果所有测试没有通过，那么就分析失败的测试，看是否是类型注释导致的，如果是，那么就修改类型注释，直到所有测试都通过
