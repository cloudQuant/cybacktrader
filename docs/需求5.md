### 核心目标

为 cybacktrader 添加 类型注释(static typing)，把能够确定的函数参数部分都增加以下静态类型注释，方便优化速度

### 实现方法

1. 阅读cython教程，了解如何增加类型注释：docs/cython_docs/en/stable
2. 阅读整个项目的160多个pyx等cython代码，分析哪些文件可以需要增加类型注释
3. 罗列出来这些文件，然后做成一个todo清单
4. 针对一个一个文件去增加类型注释，注释完成之后，测试是否注释成功
5. 使用pip install -U .  进行编译安装，使用pytest tests -n 8 进行测试，看是否所有测试都通过
6. 如果所有测试都通过，那么就提交代码
7. 如果所有测试没有通过，那么就分析失败的测试，看是否是类型注释导致的，如果是，那么就修改类型注释，直到所有测试都通过
