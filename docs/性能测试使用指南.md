# 性能测试使用指南

## 快速开始

### 运行完整性能对比

```bash
cd benchmarks
python comprehensive_performance_comparison.py
```

这将自动：
1. 生成测试数据
2. 测试 backtrader (CPython)
3. 测试 cybacktrader (CPython)
4. 测试 backtrader (PyPy)（如果可用）
5. 生成性能对比图表
6. 保存详细结果到JSON

### 输出文件

- `performance_comparison.png` - 性能对比图表
- `performance_comparison_results.json` - 详细测试数据
- `performance_comparison_data.csv` - 测试用的OHLCV数据

## 测试脚本说明

### 1. comprehensive_performance_comparison.py

**功能：** 全面的三方性能对比

**测试内容：**
- backtrader (CPython)
- cybacktrader (CPython)
- backtrader (PyPy)

**特点：**
- 自动生成测试数据
- 自动检测PyPy环境
- 生成可视化图表
- 保存详细结果

### 2. compare_python_implementations.py

**功能：** CPython vs PyPy对比

**特点：**
- 更详细的PyPy分析
- 自动检测并运行PyPy测试
- 提供优化建议

### 3. simple_pypy_test.py

**功能：** 简化的PyPy测试

**特点：**
- 不依赖pandas
- 使用现有CSV文件
- 快速测试

### 4. ma_crossover_benchmark.py

**功能：** 原有的基准测试

**特点：**
- 支持多种数据规模
- 详细的内存使用统计
- 生成完整报告

## 结果解读

### 性能图表

图表包含两部分：
1. **绝对时间对比** - 显示实际运行时间
2. **相对性能（加速比）** - 相对于基准的倍数

### JSON结果

```json
{
  "backtrader (CPython)": {
    "times": [0.4971, 0.4889, 0.4896],
    "avg": 0.4919,
    "min": 0.4889,
    "max": 0.4971,
    "std": 0.0043
  },
  ...
}
```

### 性能指标

- **avg**: 平均时间（最重要）
- **min**: 最小时间（最佳性能）
- **max**: 最大时间（最差性能）
- **std**: 标准差（稳定性指标）

## 常见问题

### Q1: PyPy测试失败

**可能原因：**
- PyPy未安装
- backtrader未在PyPy环境中安装

**解决方法：**
```bash
bash ~/setup_pypy_venv.sh
```

### Q2: 图表生成失败

**原因：** matplotlib未安装

**解决：**
```bash
pip install matplotlib
```

### Q3: pandas导入失败

**影响：** 无法生成新数据，但可以使用现有数据

**解决：**
```bash
pip install pandas numpy
```

或使用simple_pypy_test.py（不需要pandas）

### Q4: 性能结果不稳定

**原因：**
- 系统负载
- 缓存效应
- JIT预热（PyPy）

**建议：**
- 增加测试轮数
- 关闭其他程序
- 多次运行取平均

### Q5: cybacktrader未安装

**解决：**
```bash
cd /home/yun/Documents/cybacktrader
pip install -U .
```

## 高级用法

### 自定义策略测试

修改脚本中的TestStrategy类：

```python
class TestStrategy(bt.Strategy):
    def __init__(self):
        # 添加你的指标
        self.sma = bt.indicators.SMA(period=20)
        self.rsi = bt.indicators.RSI(period=14)
    
    def next(self):
        # 添加你的策略逻辑
        if self.rsi < 30:
            self.buy()
        elif self.rsi > 70:
            self.sell()
```

### 批量测试不同数据规模

```python
for size in [1000, 5000, 10000, 50000]:
```
