## 💡 核心经验

### 成功公式

```
稳定提升 = 
  深度优化关键模块（linebuffer）
  + 保守优化全部文件（language_level=3）
  + 持续测试验证
  + 避免激进策略
```

### 关键发现

1. **修复bug比优化更重要**
   - strategy.pyx的typo修复带来突破

2. **保守策略更可靠**
   - 激进编译器指令可能有害
   - 保守优化稳定可靠

3. **测试是决策依据**
   - 每次优化都要验证
   - 数据驱动决策
