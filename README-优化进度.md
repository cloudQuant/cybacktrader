## 🔧 开发流程（标准）

每个模块优化遵循：

```bash
# 1. 分析

# 2. 优化
# 编辑 .pyx 文件，添加类型声明等

# 3. 编译
pip install -U .

# 4. 测试
pytest tests -n 8
```
